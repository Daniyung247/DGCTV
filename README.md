# DGC TV News starter

## Deploy
1. Put `index.html` and `vercel.json` in the root of your GitHub repository.
2. In Vercel, import the repository.
3. Choose Framework Preset: Other. Root directory: `./`. Leave build/install commands empty; output directory `.`.
4. Deploy.

## Important limitations
This is a static visual starter. Its editorial dashboard is a browser-only demo and is NOT secure. Stories saved there are local to that browser and are not shared with visitors. The demo code is visible in the HTML. Before public use, replace the demo dashboard with Supabase authentication, server-side authorization, database RLS and image storage. Advertisement boxes are placeholders; add official AdSense code only after your account is approved. Demo stories are placeholders, not live news.
